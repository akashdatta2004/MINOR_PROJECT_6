This beginner project demonstrates a Python Flask web application with HTML templates, GET and POST routes, form validation, and a result page.

Learning objectives

  • Create routes using Flask.
  • Receive form data with a POST request.
  • Validate input and show friendly messages.
  • Render HTML templates.

Note: This version stores records in memory only. The list is cleared when the server restarts. A database is not required by the assignment.
